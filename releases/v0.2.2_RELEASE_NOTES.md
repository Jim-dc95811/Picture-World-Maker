# Picture World Maker v0.2.2 - Release notes

**Status: RELEASED 2026-11-06.**

## One obvious file

Jim's rule for every package: *one obvious .bat file to click, and everything else under a system folder* - no extras.

After you Extract All, the folder now holds just:

- `Start Picture World Maker.bat` - double-click this.
- `System Files` - everything else; leave it alone.

What moved: `START PICTURE WORLD MAKER.pyw` is now inside System Files (the .bat starts it from there). What went: `Run Picture World Maker Self Test.bat` and `README - START HERE.txt`. The user manual is on the GitHub page.

The program itself is unchanged apart from the version text in the window title. Self-test PASS (`System Files\PWM_SELF_TEST.py`, for maintainers); QGIS route, photo mode, cancel and the zoom rule behave exactly as in v0.2.1.
