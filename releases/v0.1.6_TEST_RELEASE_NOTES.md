## Defects found and fixed

| # | Problem (v0.1.5 and earlier) | What the user saw | Fix (v0.1.6) | Proof |
|---|---|---|---|---|
| 1 | Cancelled message box referred to the error after Python deleted it | Nothing - the 'Build cancelled' box never appeared (the error went to an invisible console) | Message bound immediately | Stub-window test: box shows |
| 2 | Closing the window mid-build closed at once | QGIS / GDAL kept running hidden; the temporary working folder (GBs on big jobs) stayed in %TEMP% | Close cancels, waits for the clean-up (up to 60 s), then closes | Simulated: v0.1.5 left the child running; stub-window test: closes only after the build stopped, temp folder removed |
| 3 | Cancel was only noticed when QGIS printed a line | Cancel could appear to do nothing for a long time on giant jobs | Output read on a helper thread; cancel checked every 0.2 s | Rig with a silent stand-in QGIS: 1.0 s (v0.1.5: 60.4 s) |
| 4 | Max zoom 24-25 allowed with TPKX | Hours of QGIS rendering, then 'TPKX converter failed' at the end | Checked before any work: TPKX up to 23 (Esri scheme); MBTiles-only up to 25 | Self-test + rig: refused in 0.0 s |
| 5 | A path typed into the image box was not inspected | Estimates/warnings for the previously chosen image | Typed or changed paths are inspected before building; estimate follows zoom changes | Code path test |
