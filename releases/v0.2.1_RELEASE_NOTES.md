# Picture World Maker v0.2.1 - Release notes

**Status: RELEASED 2026-11-06.** v0.2.1 = the live-proven v0.2.0 photo-mode build with its new name.

## New name

**Rasta Pyramid Factory is now Picture World Maker.** Jim (2026-11-06): *"I hate the name rasta, can you pick another name."* The name says what it does: it turns a picture into a world you can fly into.

Renamed: the repository (`Jim-dc95811/Picture-World-Maker`), the program folder, the launchers (`Start Picture World Maker.bat`, `Run Picture World Maker Self Test.bat`, `START PICTURE WORLD MAKER.pyw`), the window title, the system files (`PICTURE_WORLD_MAKER.py`, `PWM_PIPELINE.py`, `PWM_PHOTO_TILER.py`, `PWM_QGIS_WORKER.py`, `PWM_SELF_TEST.py`, `Picture_World_Maker_Config.ini`), the manual and its PDF, and the pictures. The TPKX converter `MBTiles_to_TPKX_v0_3_0.py` is unchanged apart from its description line.

**Nothing else changed.** A v0.2.1 build of Kings Reach panorama 1 has **0 structural differences** from the v0.2.0 build (`tools/tpkx_compare.py` in ArcGIS Earth Unlocked); self-test PASS.

If you have a `Rasta_Config.ini` with your own settings, copy them into `Picture_World_Maker_Config.ini` (same sections and keys).

## Photo mode (v0.2.0) - live-proven

Jim's build on 2026-11-06 00:47: Kings Reach panorama 1 (50,000 x 12,006 px) -> **55 seconds**, 35,216 tiles, 30 bundles, no QGIS - flown in ArcGIS Earth down to street level. The QGIS route took 8:46 and made a 1.77 GB TPKX; photo mode makes 442 MB. Full details: [v0.2.0_TEST_RELEASE_NOTES.md](v0.2.0_TEST_RELEASE_NOTES.md).
